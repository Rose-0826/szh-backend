## 本轮最小修正

- TaskService 将 DSH Home 交给所选数据目录，默认路径维持在 var/dsh。两组原来落在项目 var 内的测试改用系统临时目录。
- HTTP 沙箱测试复现了取消在 sleep 注册前到达时仍等待的问题。沙箱延时改用支持 AbortSignal 的 Node 定时器。生产 Run 状态与取消行为保留，竞态见上表。
- 旧 AIC 归档的交付链接改由进程环境注入。未设置时字段为 null。真实归档和原链接内容保留在本机资料中。
- 发布快照不含专业归档。无授权样例时，四项旧 AIC 测试标记跳过；原工程有样例时继续执行。显式配置样例路径而缺文件仍报错。

## 提交安全检查

- 扫描范围为客户端打磨版工程、拟提交路径及可访问的本地 Git 元数据。原工程及上级目录没有仓库历史，工程内未找到嵌套仓库或子模块。远程未发现已有分支。其他科研工程、私钥目录、远程主机、已安装依赖内容不属于此次提交。
- 待提交内容按白名单。真实 Task/Run/DSH 记录、评估归档、个人与成员交付、模型/数据集、外部 PDF、已安装依赖、截图、构建、客户端二进制、私有连接脚本及密钥文件均排除。所有原文件保留。仅保留公开资料出处、代码内的契约样例、文本测试输入和用于兼容测试的旧客户端源文件。
- 对拟提交文本查找私钥标记、常见凭据格式、内网访问定位和账户绝对路径，另检查扩展名和文件大小。运行素材和被排除二进制没有解包进入提交。扫描未命中已知模式不等同于许可或公开审查通过。MIT/OFL 声明随保留的旧前端源码留存。AIC 外部实现和模型包的再分发许可需另行确认。
- 初次发现远程是 public。用户负责变更可见性和最终 push。只有用户确认代码、许可和可见性满足要求后才上传。

## V0.1 建设顺序

1. 确认 Manifest、UI 注解、版本和输入资产标识。约定结构化校验错误，完成适配器能力与就绪校验。
2. 明确 Run 状态、幂等、取消、超时和重启恢复，再定义事件序号、阶段和终态。前后端共同约定用户能操作什么、哪些字段可能缺失。
3. 明确 Artifact 类型、大小、摘要、来源、下载授权和保留策略。验证大文件和失败诊断。
4. 在 AIC 远程接入前锁定机器权限、可信执行账号、环境、权重及样例校验值。定义远程提交、查询、取消、成果回传以及断线恢复。先以受控单版本单工况验收。
5. WWW Demo 只要求一条真实主链路可复跑。以实际 Electron 客户端提交固定版本、观察真实状态、下载可校验成果，另外演示一条受控失败。模型优化、多个专业模型和全量生态能力另行建设。
