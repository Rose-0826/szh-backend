# 使用范围

当前支持论文跑道模式和研究报告业务模式，分别使用原资料的字段与规则。

1. 调用 `notam_schema`，取得本次选定模式的字段定义和规则，不混用两种输出。
2. 调用 `notam_reference`，按字段或跑道关键词读取已收录的官方资料摘要与来源；随后按原始NOTAM识别机场与跑道方向，输出JSON数组。
3. runway模式采用五字段数组、论文默认值、机型条件与FT换算；缺少跑道编号时返回空数组。report模式采用报告案例对象，保留业务限制、否定、例外、条件和明示设施。
4. 服务检查JSON、字段、机场、已实现规则和原文对应，保存原文定位、结果与工具记录。无设施或机型映射表时不补猜，严格保留AND/OR条件。

字段与来源见runway-rules.json和report-rules.json。报告字段的工程整理差异已单独列出；已有规则直接采用，缺少的机场设施表、机型映射表和原模型接口另列。

运行时由后端装载本项Solution的字段工具与解析指令。通用Skill文件的动态装载留待后续接入。
